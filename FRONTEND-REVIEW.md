# Проверка фронтенда — 5 ноября 2026

Основание: разделы 9, 10.4 и этап 2 технического задания.

## Реализовано

- Вход, регистрация, выход; общая Zod-валидация; поля сохраняются при ошибке.
- Проверка сессии до показа страниц, защита маршрутов, возврат после входа.
- Обработка последующего 401 с отменой запросов и очисткой приватного кэша.
- Папки в URL, хлебные крошки, однократное декодирование по сегментам.
- Состояния loading, empty, error и отдельное состояние отсутствующей папки.
- Создание, переименование, выбор существующей папки для перемещения и корня.
- Подтверждение удаления, сохранение открытой формы при конфликте.
- Инвалидация папок и поиска после изменений.
- Загрузка файлов и директорий через XHR, прогресс, отмена, webkitRelativePath.
- Скачивание навигацией после проверки сессии; нет fetch/blob для реальных файлов.
- Поиск по URL с задержкой 350 мс, без отправки пустых запросов.
- Типы ответов из OpenAPI, все адреса клиента относительные.
- MSW для всех операций, отдельное состояние на пользователя и тест.
- Адаптивная раскладка; на мобильных экранах доступны все действия.

## Проверки

- 44 unit/HTTP/React-теста: маршруты и URL, строка и массив ошибок, 401,
  отсутствие мигания, возврат в папку, 404, сохранение формы после 409,
  разные строки для одноимённых файла и папки, подтверждение удаления,
  операции моков и конфликты загрузки.
- Playwright + настоящий Service Worker: вход, CRUD, upload, поиск,
  выход, потеря сессии и возвратный URL; desktop и mobile screenshots.
- Playwright + настоящий API, отдельные PostgreSQL/Redis/SeaweedFS:
  регистрация, загрузка папки с кириллицей, F5 с сохранённой сессией,
  переименование, перемещение, поиск, удаление и выход; содержимое
  скачанного файла и распакованного ZIP сверяется с фикстурой.
- Сборка, типы и oxlint. В production отсутствуют MSW и демонстрационные пароли.

Команды и режимы запуска описаны в README.

## Что относится к следующим этапам

- Сценарий e2e на полном Compose через nginx (`pnpm --filter @app/web test:full`)
  прошёл, включая F5 через Linux-образ. Деплой на VPS остаётся следующим этапом.
- Передача 1 ГиБ через nginx и SeaweedFS прошла в HTTP-проверке.
  Прогресс большой загрузки в браузере отдельно не проверялся.
- Ограничение SeaweedFS с одноимёнными файлом и папкой остаётся открытым
  пунктом бэкенда; UI различает эти ресурсы, но не меняет модель хранения.
- В MSW сессия сбрасывается после F5; настоящая cookie-сессия сохраняется,
  что проверено браузерным сценарием с API.
- ZIP автоматически распакован в тесте; ручная проверка штатными архиваторами
  Windows и macOS ещё относится к общей приёмке.
